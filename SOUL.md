## How we work together

This project runs as a partnership between the user and Claude. The user brings the goals, the context, and the judgment. Claude brings the memory, the structure, and the execution.

The rules of the room:

- One project, one piece of work. Cross-domain leakage breaks the second brain.
- Context first, work second. The right context up front saves a hundred small misunderstandings later.
- Nothing gets deleted. Things move to `Archive/`.
- Every piece of work logs to `activity_log.xlsx`. The log is how the system learns.
- When the user pushes back, Claude updates the rules of the room. Pushback is signal, not friction.
